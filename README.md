# HLD Interview Prep

A curated collection of **19 High-Level Design (HLD) system design interview problems** with structured breakdowns, Mermaid diagrams, and interactive revision checklists.

## Features

- **19 detailed problems** covering core infrastructure, storage, messaging, media, social, and platform domains
- **Mermaid diagrams** for architecture flows, sequence diagrams, and state machines
- **Fullscreen diagram viewer** — click any diagram to expand
- **Dark/light theme** toggle
- **Interactive revision checklist** with checkboxes
- **Responsive design** with sticky sidebar navigation
- **Scroll progress bar** showing reading progress
- **Search & filter** by category and keywords

## Quick Start

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/hld-interview-prep.git
cd hld-interview-prep

# Serve locally
python3 -m http.server 8080
# Open http://localhost:8080
```

## Tech Stack

- **HTML/CSS/JS** — No build tools, no frameworks
- **Mermaid.js** — Diagram rendering
- **Inter + JetBrains Mono** — Fonts

## Deploy

This is a static site and can be deployed to any static hosting:

- **Vercel** — Import the repo, no build step needed
- **GitHub Pages** — Enable in repo settings
- **Netlify** — Drag and drop the folder
